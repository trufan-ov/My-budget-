# Мой бюджет — локальная версия 1.0

Первая **новая реализация** по подтверждённым требованиям, восстановленным из `КОНТЕКСТ.md` и истории Claude. Это **не** восстановленный код Claude. Используются исключительно демонстрационные суммы; реальных финансовых данных в проекте нет.

## Состояние реализации на 18.11.2026

Рабочая PWA-версия опубликована на https://trufan-ov.github.io/My-budget-/ . Нижняя навигация на телефоне содержит четыре пункта: Главная, Операции, План и Ещё.

Реализовано: локальное хранение и JSON-резервные копии, несколько счетов, внутренние переводы, цели и рассрочки, прогнозы на 3/6/12 месяцев, зарплатные правила, импорт CSV/XLSX с постраничным предпросмотром и отменой импорта, долги и кредитные карты с ручным погашением, ориентировочные аннуитетные графики, календарь обязательств, аналитика расходов и браузерные тесты Chromium/WebKit.

**Не заявляется как реализованное:** прямой импорт устаревшего бинарного XLS, автоматическая банковская синхронизация, точный расчёт льготных периодов/комиссий/изменяющихся ставок, импорт произвольных банковских форматов без настройки колонок, реальная синхронизация между устройствами, тестирование на физическом iPhone. График кредита носит оценочный характер, платежи учитываются только после подтверждения.

**Важное ограничение:** приложение хранит реальные данные в браузере текущего устройства. Очистка данных браузера может удалить бюджет. Перед экспериментами сохраняйте JSON-резервную копию.

## Что работает

- Фактические доходы и расходы; категории, история, редактирование простых операций и удаление.
- Дополнительный доход с выбором суммы для немедленного перевода в копилку — один сценарий с двумя связанными операциями.
- Переводы туда/обратно; учёт фактических процентов; расчёт доступного остатка и копилки из истории операций.
- Отмена операции; при удалении связанного дополнительного дохода удаляется и связанный перевод.
- Зарплатные правила 7-го и 23-го числа (в демо по 33 000 ₽), с переносом с выходных на пятницу; суммы демонстрационные.
- Регулярные расходы и разовые плановые события; подтверждение события как фактической операции, чтобы не учитывать его повторно в прогнозе.
- Лимит на день до следующей зарплаты с резервированием запланированных обязательств.
- Помесячный прогноз на полгода. Процент по копилке моделируется приблизительно и не начисляется фактически без операции.
- Настройки, экспорт и восстановление JSON, хранение в IndexedDB.
- Мобильная адаптация и веб-доступ через локальную сеть, PWA-кеш при запуске через localhost/HTTPS.

## Требования

- Windows 10/11, **Node.js 20+** (лучше актуальная LTS с https://nodejs.org/).
- Современный Chrome/Edge или Safari на iPhone.
- Интернет **не требуется** после установки Node.js: в проекте нет внешних npm-зависимостей.

## Запуск на Windows

1. Распакуйте ZIP **целиком** в отдельную папку, например `C:\moy-budget`.
2. Установите Node.js LTS с https://nodejs.org/, если его ещё нет.
3. Дважды нажмите `start-windows.bat`.
4. Откройте на компьютере **http://localhost:4173**.
5. Оставьте окно сервера открытым, пока пользуетесь приложением. Остановить: `Ctrl+C`.

Если Windows показывает предупреждение брандмауэра, разрешите доступ **только для частных сетей**, если хотите подключаться с iPhone. Не перенаправляйте порт 4173 в интернет.

Альтернатива через PowerShell в папке проекта:

```powershell
node server.mjs
```

## На iPhone

1. Подключите Windows-компьютер и iPhone к **одной Wi-Fi сети**. Не используйте гостевую сеть с изоляцией клиентов.
2. Запустите сервер на Windows (окно `start-windows.bat`).
3. В окне появится адрес наподобие `http://192.168.1.25:4173` (на вашем компьютере IP будет **другим**).
4. Откройте **этот точный адрес** в Safari на iPhone. Если не открывается — проверьте настройки брандмауэра Windows и доступ устройств друг к другу.
5. На iPhone приложение доступно, пока запущен сервер на ПК и устройства находятся в общей сети.

**Ограничение:** HTTP-сайт по адресу локальной сети не является безопасным контекстом для Service Worker на iPhone, поэтому полноценный офлайн-режим/PWA-установка на iPhone пока **не гарантируются**. Для этого на следующем этапе понадобится HTTPS или специальная локальная сборка. При этом само приложение хранит данные на каждом устройстве **отдельно**; данные с Windows не синхронизируются автоматически с iPhone. Используйте экспорт JSON → импорт JSON, чтобы перенести их вручную. Настоящее использование без Windows-сервера не входит в эту версию.

## Прогон тестов

Откройте PowerShell в папке проекта:

Тесты используют встроенный модуль Node.js, установки зависимостей не требуется.

## Финансовая модель

- Все суммы хранятся **в целых копейках**.
- Доход увеличивает только доступные средства; расход уменьшает только доступные средства.
- Внутренний перевод изменяет доступный и накопительный балансы на противоположные значения, не изменяя общую сумму активов.
- Плановый доход или расход **не меняет** фактический остаток до ручного подтверждения.
- Плановый платеж учитывается как резерв до следующей зарплаты; после подтверждения он исчезает из числа будущих событий.
- Лимит = max(0, доступный остаток − ближайшие обязательства) / календарные дни до следующей зарплаты. Резерв на необязательные будущие траты и стратегия распределения дополнительных доходов по дням ещё не реализованы.
- Прогноз считает будущие регулярные и разовые события, а также примерную капитализацию процентов на копилку; **не учитывает** прогнозные бытовые расходы, инфляцию, налоги, комиссии, среднедневной остаток и точные банковские правила начисления процентов.

## Известные ограничения

- Демоданные и правила — пример, а не актуальные пользовательские значения.
- Нет входа в аккаунт, облачной синхронизации, автоматического импорта банковских операций и пуш-уведомлений.
- Подтверждение планового события всегда проводится сегодняшней датой; ручное редактирование фактической даты выполняется через историю.
- Для автоматических платежей дата повторения выбирается 1–28; повторяющиеся правила можно добавлять/удалять, но не редактировать (удалить и создать новое).
- Редактирование связанного сценария «доход + копилка» реализуется удалением и созданием заново, чтобы сохранить корректную связь.
- Существуют операции, выполненные позже даты редактируемой операции: в этой версии нет полной проверки отрицательных промежуточных остатков при правке задним числом.
- Локальные браузерные данные можно потерять при очистке хранилища. Делайте экспорт JSON перед экспериментами.
- Автоматические тесты финансового ядра **не являются** полноценным браузерным E2E-тестированием на Windows и iPhone.

## Файлы

- `src/core.mjs` — чистая финансовая модель и сценарии.
- `src/storage.mjs` — IndexedDB, резервные копии.
- `src/app.mjs` — интерфейс, формы, действия пользователя.
- `styles.css` — адаптивный интерфейс.
- `server.mjs` — простой локальный HTTP-сервер Node.js.
- `tests/core.test.mjs` — автоматические тесты.
- `manifest.webmanifest`, `sw.js`, `icon.svg` — PWA-ресурсы.
