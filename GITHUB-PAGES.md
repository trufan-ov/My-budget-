# Публикация «Мой бюджет» — GitHub Pages (iPhone)

## Один раз: загрузка файлов

1. Войти в GitHub и создать **новый публичный репозиторий**, например `moy-budget` (без автосоздания README).
2. Открыть репозиторий → `Add file` → `Upload files` и загрузить **содержимое папки `moy-budget-v1`** (не саму папку). В веб-интерфейсе GitHub загрузка скрытой папки `.github` может не сработать: при необходимости загрузите файлы через Git (см. ниже).
3. В `Settings` → `Pages` → `Build and deployment` → `Source` выбрать **GitHub Actions**.
4. В разделе `Actions` дождаться успешного выполнения `Publish My Budget to GitHub Pages`.
5. Открыть URL, который показывает Pages (обычно `https://USERNAME.github.io/moy-budget/`).

**Надёжный способ для Windows через Git**, если обычная загрузка файлов не передала `.github/workflows/pages.yml`:

```powershell
cd C:\path\to\moy-budget-v1
git init
git branch -M main
git add .
git commit -m "Initial My Budget PWA"
git remote add origin https://github.com/USERNAME/moy-budget.git
git push -u origin main
```

Нужно предварительно установить Git for Windows, создать пустой репозиторий и заменить `USERNAME` и путь на свои. GitHub может запросить вход через браузер; не вставляйте токены в переписку.

## Добавить на iPhone

1. Открыть выданную HTTPS-ссылку в **Safari**.
2. Нажать «Поделиться» → «На экран Домой» → «Добавить».
3. После первого успешного подключения (когда файлы сохранены в кеш) приложение может работать без сети. **Офлайн-работу на конкретной версии iOS надо проверить вручную**: включить авиарежим и открыть иконку.

## Данные и безопасность

- В репозиторий загружается **только код с демоданными**. Твои операции хранятся в IndexedDB конкретного браузера/установленного веб-приложения.
- GitHub Pages — **общедоступный сайт**. У приложения пока нет авторизации: любой, кому известна ссылка, сможет открыть копию программы, но не твои локально сохранённые операции.
- На iPhone и компьютере базы данных не синхронизируются. iOS может разделять хранилища Safari и приложения, добавленного на экран «Домой». Перед переходом экспортируй JSON и импортируй в нужное приложение.
- Перед очисткой данных Safari, переустановкой приложения и обновлениями выгружай резервную копию JSON. На первой версии не рекомендуется хранить единственный экземпляр ценных данных.
- Если приложение обновилось, а Safari показывает старый интерфейс, обнови страницу онлайн; при проблемах — проверь кеш сервис-воркера, но **не удаляй данные сайта без экспорта**.

## Запуск локально

`start-windows.bat` или `npm start` → `http://localhost:4173/`.
Запуск через `file://` не подходит для IndexedDB и Service Worker.
