# Публикация «Мой бюджет» через GitHub Pages

Рабочий сайт — [«Мой бюджет»](https://trufan-ov.github.io/My-budget-/). Репозиторий публикует корень ветки `main` через GitHub Pages. Обычное изменение не требует менять настройки Pages.

1. Создайте рабочую ветку и проведите проверки из `AGENTS.md`.
2. Откройте PR в `main`, дождитесь успешного завершения `Finance tests` и объедините PR.
3. В `Actions` дождитесь успешного `pages build and deployment` для точного коммита в `main`.
4. Откройте публичный сайт и проверьте, что публичный `sw.js` объявляет версию кеша выпуска. При изменении ресурсов приложения обновляйте версию кеша в `sw.js`.

## Установка на iPhone

1. Откройте рабочий сайт в Safari.
2. Выберите «Поделиться» → «На экран Домой» → «Добавить».
3. Дождитесь полной загрузки онлайн. Для проверки повторно откройте приложение в авиарежиме.

Бюджет хранится в IndexedDB конкретного браузера или установленного веб-приложения. Для переноса между устройствами воспользуйтесь экспортом и восстановлением JSON. Перед очисткой данных Safari сохраните копию.

## Локальный запуск

Команда `node server.mjs` запускает приложение на `http://localhost:4173/`. Для офлайн-режима service worker нужен localhost или HTTPS.
